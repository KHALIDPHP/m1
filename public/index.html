اتصال جديد بالراوتر

كيف أقوم بإعداد المايكروتك ليتصل بالإنترنت؟
  1. قم بتسجيل الدخول للراوتر عبر برنامج Winbox.
  2. اذهب إلى IP -> Services وقم بتفعيل الخدمة api (منفذ 8728) أو api-ssl (منفذ 8729).
  3. للاتصال من خارج الشبكة، قم بتفعيل خدمة الـ DDNS المجانية بالذهاب إلى IP -> Cloud وتفعيل خيار DDNS Enabled ثم نسخ العنوان الظاهر.
  4. إذا كان المايكروتك خلف مودم إنترنت، يجب عمل Port Forwarding للمنفذ 8728 أو 8729 من المودم إلى الآيبي الخاص بالمايكروتك.
